# Coach search · prototype

Type what your company needs, in German or English. The search understands city, budget and format, finds matching coaches by meaning and keywords, and shows the sentence that made each coach match.

All 30 coach profiles are invented for this demo. Code and evaluation: [github.com/Viswas-Vinayakumar/AI-search](https://github.com/Viswas-Vinayakumar/AI-search)
